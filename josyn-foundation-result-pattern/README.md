# josyn-foundation-result-pattern

Dieses Sub-Repo enthält das NuGet-Paket **`JOSYN.Foundation.ResultPattern`** —
das zentrale Fehlerbehandlungs-Paket von JOSYN.

→ [Paketdokumentation](JOSYN.Foundation.ResultPattern/README.md)

---

## Bauen, Testen, Packen

```
.local-build\build.cmd          # Release-Build
.local-build\build.cmd Debug    # Debug-Build
.local-build\test.cmd           # Alle Tests ausführen
.local-build\pack.cmd           # NuGet-Paket erzeugen → ..\..\local-packages\
```
